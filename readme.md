
# Charybdis Nano (3x5) / Slinky v3 vial Firmware

This repository contains the firmware for the **Charybdis Nano** (Charybdis 3x5) split keyboard, built with the **Slinky v3** controller.

## Features

- Supports **combos**, **tap dance**, and **key overrides**
- Includes **32 macros**
- Fixed an issue where the keyboard required a USB reconnection when the computer starts up
- RGB lighting has **not been tested**
