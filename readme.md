
# Charybdis Nano (3x5) / Splinky v3 — Vial Firmware

This repository contains the Vial firmware for the
[Charybdis Nano](https://bastardkb.com/) (3x5) split keyboard,
built with the Splinky v3 controller.

This is a personal fork/build, **not an official BastardKB release**.
It is not maintained by or affiliated with Bastard Keyboards.

## Features

- Supports combos, tap dance, and key overrides
- Includes 32 macros
- Fixed an issue where the keyboard required a USB reconnection when
  the computer starts up
- RGB lighting has not been tested
